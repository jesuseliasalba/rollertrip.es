# RollerTrip.es

[![Vercel](https://vercelbadge.vercel.app/api/jesuseliasalba/rollertrip.es)](https://rollertrip-es.vercel.app)

## 📌 Descripción

**RollerTrip.es** es una aplicación web dedicada a la comunidad de patinadores,
ofreciendo información sobre eventos, rutas y noticias relacionadas con el mundo del patinaje.

## 📂 Estructura del Proyecto

```
rollertrip.es/
│── public/             // Archivos estáticos y `index.html`
│── src/                // Código fuente principal
│   ├── components/     // Componentes reutilizables
│   ├── App.jsx         // Componente principal
│   ├── main.jsx        // Punto de entrada de la aplicación
│── .gitignore          // Archivos ignorados por Git
│── package.json        // Configuración y dependencias del proyecto
│── vite.config.js      // Configuración de Vite
```

## 🚀 Tecnologías Utilizadas

- **React** - Biblioteca principal para la construcción de la interfaz de usuario.
- **Vite** - Herramienta de construcción y desarrollo rápido para proyectos de frontend.
- **Material-UI (MUI)** - Biblioteca de componentes de interfaz de usuario para React.
- **React Router** - Utilizado para la gestión de rutas dentro de la aplicación.

## ⚡ Instalación y Ejecución

Para ejecutar este proyecto localmente, sigue estos pasos:

```bash
git clone https://github.com/jesuseliasalba/rollertrip.es.git
cd rollertrip.es
npm install
npm run dev
```

La aplicación estará disponible en **`http://rollertrip.es`**.
